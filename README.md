# 🎁 Адвент-календар із призами

Адвент-календар на чистому HTML/CSS/JS. Кожен приз має **координати**, а призи можна
**розкладати за різними варіантами** (сітка, ялинка, розкидані, хвиля). Адаптивно
працює на десктопі й мобілці. Прогрес (відкриті віконця) зберігається в браузері.

## 🚀 Демо

Після увімкнення GitHub Pages сайт буде доступний за адресою:

```
https://<your-username>.github.io/advent-prizes/
```

## ⚙️ Як налаштувати

Усе редагується в одному файлі — [`js/data.js`](js/data.js).

### Призи

```js
const PRIZES = [
  { day: 1, title: 'Знижка 10%', description: 'Промокод', image: 'images/prize-01.svg' },
  // ...
];
```

Щоб поставити свою картинку — поклади файл у `images/` і вкажи шлях у полі `image`
(підтримуються `.svg`, `.png`, `.jpg`, ...).

### Координати та варіанти розкладки

У `LAYOUTS` описані варіанти. Підтримуються **два режими координат**:

| Режим    | Координати                | Опис                                         |
|----------|---------------------------|----------------------------------------------|
| `grid`   | `{ row, col }`            | Рівна сітка. `row`/`col` від 1.              |
| `free`   | `{ x, y }` у відсотках    | Вільне розміщення. `x`/`y` = центр клітинки. |

```js
const LAYOUTS = [
  { id: 'grid', name: '🔲 Сітка', type: 'grid', cols: 6, positions: { 1: { row: 1, col: 1 }, /* ... */ } },
  { id: 'tree', name: '🎄 Ялинка', type: 'free', positions: { 1: { x: 50, y: 8 }, /* ... */ } },
];
```

Координати у відсотках (`free`) масштабуються разом із полем, тому однаково
лягають на будь-якому екрані. Додавай скільки завгодно власних варіантів —
кнопки для них з'являться автоматично.

## 🛠 Локальний запуск

Це статичний сайт — достатньо відкрити `index.html`. Або підняти простий сервер:

```bash
python3 -m http.server 8000
# відкрий http://localhost:8000
```

## 📦 Деплой на GitHub Pages

Деплой автоматичний через GitHub Actions — workflow у
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

**Одноразове налаштування:** у репозиторії відкрий
**Settings → Pages → Build and deployment → Source** і обери **GitHub Actions**.
Після цього кожен push публікує сайт автоматично.

## 🗂 Структура

```
.

├── css/styles.css          # стилі + адаптив
├── js/
│   ├── data.js             # призи, координати, варіанти розкладок ← редагуй це

├── images/                 # картинки призів
└── .github/workflows/      # автодеплой на Pages
```
